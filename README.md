# AVANTI COSMETIC – Mbagala factory

3D walkthrough and project book for the AVANTI COSMETIC factory conversion, Mbagala, Dar es Salaam (Ground + 2 floors, All Floors Rev.A, 16.11.2026).

- `index.html` – project page: project book (73 sheets), proposals, renders, 3D preview
- `walk.html` – full-screen 3D walkthrough: guided tour, first-person walk-through tour, floor/room navigation
  - `walk.html?tour=1` starts the guided tour automatically
  - `walk.html#lobby` opens a room directly

Open in Chrome or Safari (not inside WhatsApp/Telegram in-app browsers).
